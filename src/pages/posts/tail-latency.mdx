# The request that everyone waits for

An average compresses a crowd into one number. That makes it useful for capacity planning and dangerous for explaining experience. A service can answer most requests quickly while a small tail waits on cold code, a congested dependency, or a cache miss. Users notice the request that holds the page open, not the arithmetic mean of everything that finished before it.

## Read the shape, not only the percentile

The line above orders sanitized static-asset fetch durations from this blog engine, not end-to-end browser latency. Each cyan point is a preceding request; the amber point is the latest. Their shared vertical scale makes the immediate comparison explicit. The p95 marker asks a concrete question: how long did nineteen out of twenty requests in the current window finish within?

The display is a projection, not a log. The server discards paths, network addresses, user agents, headers, and request bodies. It retains only a capped duration, an allowlisted route class, a coarse status class, and an observation timestamp. At most 300 points may exist inside the current 60-second presentation window. The same timestamp boundary governs SQLite deletion, snapshots, replay, and browser rendering; a point that ages out is physically deleted and cannot return on reconnect.

## A tail is a coordination problem

Tail latency often grows where independent delays meet. One request may need several resources, and the slowest resource gates the result. Retries can amplify the same congestion they attempt to escape. Queueing turns a brief burst into a longer wait. The useful response is not to worship one percentile; it is to locate which bounded class of work moves into the tail, then test whether the reducer’s next projection moves back.

This essay’s chart follows that discipline. Network handlers validate and buffer projections. The browser renders at its own cadence, updates persistent line and area paths, and reuses point circles by key. When the chart leaves the viewport, its page-level connection closes. If realtime delivery is unavailable, the static snapshot remains readable.
